Навантажувальне тестування:

Тест написаний на k6, сценарій лежить у loadtest/test.js.

Сценарій:

Кожен віртуальний користувач за один візит робить 1 запис і 9 читань: створює нотатку (POST /notes, потрібен JWT), потім читає щойно створену нотатку і ще вісім сусідніх (GET /notes/:id). Співвідношення записів і читань 10 до 90.

Фази:

1. Зростання від 0 до 60 користувачів за 3 хвилини.
2. Утримання 60 користувачів 5 хвилин.
3. Спад до 0 за 2 хвилини.

Разом 10 хвилин.

Команда запуску:

k6 run -e BASE_URL=http://<alb> -e ADMIN_PASSWORD='...' loadtest/test.js

Запуск без кешу:

k6 run -e BASE_URL=http://<alb> -e ADMIN_PASSWORD='...' -e NOCACHE=1 loadtest/test.js

ADMIN_USERNAME за замовчуванням admin.

Результати:

Вставити після двох живих прогонів. Не заповнювати оцінкою.

Показник | Без кешу | З кешем
Запитів усього | | 
Запитів за секунду | | 
Невдалих запитів | | 
Затримка p50 | | 
Затримка p95 | | 
Затримка p99 | | 

Сюди ж вставити підсумки k6 без кешу і з кешем.

Під час обох тестів мають спрацювати автомасштабування, дашборд і лист. Опис у docs/AUTOSCALING.md, docs/ALERTS.md і docs/CACHE.md.
